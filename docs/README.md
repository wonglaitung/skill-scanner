# docs 文档索引

本目录只保留当前有效文档，不维护修订记录。内容文档合并为 3 份：

| 文档 | 用途 | 主要读者 | 什么时候读 |
|---|---|---|---|
| [`assistant/skill-release-guide`](../assistant/skill-release-guide/SKILL.md) | 唯一用户入口：初始化、检查、3 轮基线、Gate、L3、报告 | Skill 作者、安全工程 | 第一次扫描或执行完整流程时 |
| [`Skill 检查使用指南.md`](Skill%20检查使用指南.md) | S/L/Agent 定级、最低检查矩阵、运行前置、报告解读、排障、手动与批量命令 | Skill 作者、Owner、审核人 | 定级、运行前、解读报告或排障时 |
| [`Agent Skill 工程化检查方案与生产路线.md`](Agent%20Skill%20工程化检查方案与生产路线.md) | 方案源：威胁模型、检查框架、工具链、门禁、路线图、Phase A-D 与验收 | 方案负责人、安全工程、架构 | 做方案决策、排期或验收时 |
| [`对抗审核报告模板.md`](对抗审核报告模板.md) | 独立对抗审核报告模板 | 安全审核人 | 输出人工审核报告时 |

## 阅读顺序

1. 用 [`assistant/skill-release-guide`](../assistant/skill-release-guide/SKILL.md) 走完整流程。
2. 用 [`Skill 检查使用指南.md`](Skill%20检查使用指南.md) 定级、准备运行前置、解读报告或排障。
3. 需要理解设计取舍、排期或验收时读 [`Agent Skill 工程化检查方案与生产路线.md`](Agent%20Skill%20工程化检查方案与生产路线.md)。
4. 输出独立审核报告时使用 [`对抗审核报告模板.md`](对抗审核报告模板.md)。

## 文档边界

- 操作流程只在入口 Skill 维护。
- S/L/Agent 定级、运行前置、报告解读和排障只在 [`Skill 检查使用指南.md`](Skill%20检查使用指南.md) 维护。
- 方案决策、工具链、门禁和路线图只在 [`Agent Skill 工程化检查方案与生产路线.md`](Agent%20Skill%20工程化检查方案与生产路线.md) 维护。
- 审核报告格式只在 [`对抗审核报告模板.md`](对抗审核报告模板.md) 维护。

## 不放在这里的内容

- 历史试点报告
- 已废弃的术语和内部代号
- 与当前工具链冲突的调研材料
- 一次性运行报告（放在 `reports/`，不入库）
